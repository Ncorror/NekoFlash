# NekoFlash brand references from Legacy

Эти файлы извлечены из Legacy-материалов и сохранены **без визуальной переработки** как исходная точка новой NekoFlash identity.

- `welcome-background-reference.jpg` — 900×1600, чистый фон Welcome.
- `welcome-legacy-reference.png` — 945×2048, реальный Legacy Welcome screen с прежним onboarding UI.
- `nekoflash-icon-reference.png` — 1254×1254, реальная Legacy NekoFlash icon reference.

Правило нового проекта:
- сохраняем узнаваемость/атмосферу/кошачью USB identity;
- не обязаны копировать старый экран пиксель-в-пиксель;
- старые permission/risk gates не переносятся как product authorization;
- при финальной подготовке adaptive/monochrome icons и artwork derivatives сохраняем source attribution/history внутри repository.
